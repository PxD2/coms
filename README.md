# coms

**the data is the os.**

coms (capability-oriented memory system) is a future operating system whose kernel objects are data: identity, tier, lineage, capability. Processes, GPUs, and networks are tenants.

PMOC (Parallel Memory Optimized Compute) is the layout. Stay and Future kernels keep abandoned PCs alive. coms is the plane that does not exist on Windows, Linux, CUDA, or ROCm today.
