# coms Python

Built into the coms OS as **studio**. Not an optional marketplace item.

- Editor: Monaco (the VS Code editor core)
- Run: Python 3 against the PMOC plane (`plane()`, `tiers()`)
- Completions: print, def, class, coms APIs
- Outline + diagnostics live in the window

Open **studio** on the coms desktop. F5 or Run.
